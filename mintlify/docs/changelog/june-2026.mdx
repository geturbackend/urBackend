<Update label="2026-06-01" description="Week of 2026-05-25–2026-06-01" tags={["Feature", "Improvement", "Fix", "Security"]}>
## New features

- You can now export databases asynchronously through a queue-based pipeline for improved performance.
- You can now recover soft-deleted records for better data management.
- You can now return to the home page from the signup page using the new **Home** button.
- You can now jump back to the top of long pages using the new **Back to Top** button.

## Improvements

- You now get standardized formatting across editors via `.editorconfig`.
- You benefit from faster sync webhook dispatch, now offloaded to `bullmq`.
- You get a cleaner onboarding experience with an updated `.env.example` and added source comments.
- You get improved code quality via the new `husky` and `lint-staged` pre-commit hook.

## Bug fixes

- Fix dashboard get data query engine (#230)
- Fix query engine limit fields mock (#231)
- Enforce SameSite=Lax on all cookies to prevent CSRF attacks (#240)
- Patch storage quota evasion loophole in update pipeline (#224)
- Add missing max length constraints to auth schemas (#221)
- Add timeout handling for OAuth fetch requests (#220)
- Pin root dependency versions (#236)
